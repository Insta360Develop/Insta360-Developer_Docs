# Link 系列 SDK

Link 系列提供 **UVC Camera SDK**,用于发现并控制通过 USB 连接的 Link 系列摄像头,覆盖 Windows、macOS、Linux 三个平台。

::: warning 独立的 SDK
Link 系列的 SDK 与 X / ACE / GO 系列**不通用**,接口完全独立,请勿参照 X 系列文档接入。
:::

SDK 源码与示例工程托管在 GitHub:**<https://github.com/Insta360Develop/Link-SDK>**

Link、Link 2、Link 2C、Link 2 Pro、Link 2C Pro

## 支持平台

Windows、macOS、Linux(Ubuntu 22.04)
