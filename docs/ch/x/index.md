# X 系列 SDK

X 系列产品的开发者文档。X 系列是目前覆盖最完整的系列：提供 Android、iOS、桌面端 SDK，以及独立的 **OSC 协议**。

## 平台支持

| 文档集 | 状态 | 入口 |
| --- | --- | --- |
| Android SDK | ✅ 已支持 | [集成指南](./android/guide/) · [接口文档](./android/api/) |
| iOS SDK | ✅ 已支持 | [集成指南](./ios/guide/) · [接口文档](./ios/api/) |
| 桌面端 SDK | ✅ 已支持 | [集成指南](./desktop/guide/) · [接口文档](./desktop/api/) |
| OSC 协议 | ✅ 已支持 | [协议说明](./osc/guide/) · [接口文档](./osc/api/) |

::: tip 该选哪一套？
- 原生 Android 应用 → **Android SDK**
- 原生 iOS 应用 → **iOS SDK**
- Windows / macOS 桌面应用 → **桌面端 SDK**
- 跨语言 / 通过 HTTP 直接控制相机 → **OSC 协议**
:::

每套文档都包含：集成指南（快速入门）、接口文档、版本更新记录、重要提示。
