# Android SDK 集成指南

本指南帮助你在 **15 分钟内**完成 Android SDK 的接入：从添加依赖、初始化，到完成第一次调用。

::: tip 阅读顺序建议
1. [快速入门](./quickstart) —— 跑通最小可用示例
2. [安装与初始化](./installation) —— 了解依赖、权限与初始化细节
3. [接口文档](../api/) —— 查阅每个接口的完整参数说明
:::

## 适用范围

| 项目 | 要求 |
| --- | --- |
| 最低系统版本 | Android 7.0 (API 24) |
| 编译 SDK 版本 | API 33+ |
| 语言 | Kotlin / Java |
| 架构支持 | arm64-v8a、armeabi-v7a |

## 集成流程概览

> 添加依赖 → 申请权限 → 初始化 SDK → 连接设备 → 调用业务接口
