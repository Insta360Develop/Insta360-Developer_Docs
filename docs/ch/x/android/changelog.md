# 版本记录

## V1.10.1

1. 支持 16 KB 内存页
2. 提升 SDK 稳定性

## V1.9.11

1. 支持配置日志输出等级与缓存等级
2. 修复 X3 相机 HDR 模式下曝光异常的问题
3. 修复 X3 相机视频分辨率设置不生效的问题
4. 修复两个单鱼眼文件拼接时出现黑帧的问题

## V1.9.4

1. 支持 X4 Air
2. 此版本不支持 16K(V1.8.2 支持)
3. 修复 V1.9.3 版本中直播功能的崩溃问题

## V1.9.3

1. 支持 X4 Air
2. 此版本不支持 16K(V1.8.2 支持)

## V1.8.2-build4

1. 支持 16 KB 内存页
2. 新增色彩增强(Color Plus)接口
3. 新增设置 Wi-Fi 国家码与信道的方法
4. 新增拍照倒计时功能(仅 X5)
5. 预览支持全景平铺渲染模式
6. 修复蓝牙连接下相机电池状态未上报的问题
7. 修复直播分辨率参数与实际输出不一致的问题

## V1.8.1-build6

1. 新增视频降噪导出接口
2. 新增日志数据导出接口
3. 新增相机锁屏控制接口(仅 X4、X5)
4. 新增去紫边接口(仅 X5)
5. 新增相机拍摄异常回调接口
6. 修复蓝牙连接后部分参数无法设置的问题
7. 修复 X2/X3 设备直播时的崩溃问题
8. 修复直播码率设置不生效的问题

## V1.8.0-build11

1. 支持 Insta360 X5
2. 新增获取相机支持的配置参数的能力
3. 更新防抖算法,画面更流畅
4. 完善错误码体系,信息更详细
