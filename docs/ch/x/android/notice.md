# 重要提示

接入前请务必阅读以下关键信息，可避免大多数常见问题。

## 权限

- SDK 依赖 **相机** 与 **存储** 权限，Android 6.0+ 需在运行时动态申请。
- 缺少 `INTERNET` 权限会导致连接始终失败且无明确报错。

## 兼容性

| 项目 | 说明 |
| --- | --- |
| 最低系统 | Android 7.0 (API 24) |
| ABI | 仅提供 `arm64-v8a`、`armeabi-v7a`，模拟器需 ARM 镜像 |
| 多进程 | SDK 不支持跨进程调用，请在主进程初始化 |

## 已知问题

::: warning
- 部分国产 ROM 的省电策略会在后台杀死连接，建议引导用户加入白名单。
- 同时初始化多个 `SdkManager` 实例为未定义行为，请保持单例。
:::

## 最佳实践

- 在 `Application` 中初始化，避免重复 `init`。
- 所有回调默认在主线程，耗时操作请切换线程。
- 发布包请按[安装与初始化](./guide/installation)配置混淆规则。
