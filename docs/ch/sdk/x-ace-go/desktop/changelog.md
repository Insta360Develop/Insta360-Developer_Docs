# 版本记录

桌面端 SDK 按平台分别记录,每条同时标注 Camera SDK 与 Media SDK 的版本号。

## Windows

### Camera-V2.2.4、Media-V3.2.0

**更新时间**:2026-11-09

1. 提升 X6 文件下载速度
2. 优化 URL 回调机制
3. 优化 SDK 稳定性,修复若干已知问题

### Camera-V2.1.8、Media-V3.2.0

**更新时间**:2026-11-02

1. 支持 X6
2. 优化 SDK 稳定性,修复若干已知问题

### Camera-V2.1.8、Media-V3.1.5

**更新时间**:2026-08-28

1. 支持 X6
2. 新增文件尾解析工具,支持解析相机型号、固件版本、序列号、IMU、曝光时间等信息
3. 优化 SDK 稳定性,修复若干已知问题

### Camera-V2.1.1、Media-V3.1.3

1. 修复使用最新 NVIDIA 显卡驱动出现硬件编码失败的问题

### Camera-V2.1.1、Media-V3.1.0

1. 支持 X4 Air
2. 优化模型设置路径接口
3. 添加录像状态通知回调
