# Release Notes

Each desktop release ships both a Windows and a Linux build. If a platform has no update in a given release, its previous release notes are listed alongside.

## Camera SDK

### Windows V2.1.1 / Linux V2.1.1 (Latest)

**Windows V2.1.1**
1. Support X4 Air

**Linux V2.1.1**
1. Support X4 Air

### V2.0.2-build1 (Windows & Linux)

1. Supports Insta360 X5
2. Supports GPU stitching only
3. Added preview stream stitching function
4. Added the function of removing purple fringing
5. Added firmware version detection API
6. Added logging function
7. Added anti-flicker feature
8. Updated AI stitching model for better image quality
9. Improved error code system with more detailed prompts

## Media SDK

### Windows V3.1.3 / Linux V3.1.1 (Latest)

2. Optimized the model path setting interface

**Linux V3.1.1**

**Linux V3.1.1**

2. Optimized the model path setting interface

### V3.0.5-build1

**Windows V3.0.5-build1**
1. Fixed a crash caused by short Timelapse clips
2. Fixed an issue where CUDA detection was still performed despite the disable_cuda parameter being set

**Linux V3.0.5-build1**
1. Media SDK now supports headless mode
2. Added SetImageProcessingAccelType interface to address crashes caused by missing GPU support
3. Fixed a crash caused by short Timelapse clips
4. Fixed a crash when exporting image sequences
5. Fixed a crash caused by applying chromatic calibration on AWS cloud hosts
6. Fixed an issue where CUDA detection was still performed despite the disable_cuda parameter being set
