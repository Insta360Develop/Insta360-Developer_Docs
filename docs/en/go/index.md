# GO Series SDK

The GO series currently provides an **Android SDK**. It is **the same SDK** as the X series — identical APIs and usage. iOS and Desktop are planned.

| Desktop SDK | 🕒 Planned | — |

::: info Shares the SDK with the X series
The X, ACE and GO series use the same SDK and therefore share one set of docs; only the supported camera models differ. Where an API notes a model restriction, that note takes precedence.
:::
