# Release Notes

## V1.9.2

1. Support X4 Air
2. Added method to set Wi-Fi country code and channel
3. Added photo countdown function (X5 and X4 Air only)

## V1.8.2-build4

1. Added video denoising export interface
2. Added camera lock screen control interface (X4 and X5 only)
3. Added callback interface for camera shooting exceptions
4. Added Color Plus interface
5. Added GPS location embedding interface for shooting
6. Upgraded library format to .xcframework

## V1.8.1-build1

1. Supports Insta360 X5
2. Added the ability to retrieve supported camera configuration parameters
3. Added the function of removing purple fringing
4. Added logging functionality
5. Updated image stabilization algorithm for smoother footage
6. Improved error code system with more detailed information
