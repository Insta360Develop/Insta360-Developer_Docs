# Link Series SDK

The Link series provides the **UVC Camera SDK**, which discovers and controls Link series cameras connected over USB on Windows, macOS and Linux.

::: warning A separate SDK
The Link series SDK is **not interchangeable** with the X / ACE / GO SDK — its APIs are entirely independent, so do not integrate against the X series docs.
:::

The SDK source and sample projects are hosted on GitHub: **<https://github.com/Insta360Develop/Link-SDK>**

## Supported cameras

Link, Link 2, Link 2C, Link 2 Pro, Link 2C Pro

## Supported platforms

Windows, macOS, Linux (Ubuntu 22.04)
